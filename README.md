# Мур.архив

Мобильный фотоальбом Джузо и Моти на React, Vite и Three.js. В галерее шесть фотографий. Избранное хранится в браузере.

В «Мур.почте» можно сделать открытку из любого кадра, выбрать бумагу и стикер, добавить подпись и сохранить PNG 1080 × 1350. Открытка создаётся прямо в браузере.

Кнопка «Добавить фото» сохраняет выбранные снимки в браузере. Они доступны в фильтре «Мои фото» и в «Мур.почте» после обновления страницы.

## Запуск

```sh
yarn install
yarn dev
```

Для сборки выполните `yarn build`. Готовый сайт появится в папке `dist`.

В 3D-сцене можно потянуть фигурки мышью или пальцем. С клавиатуры ракурс меняется стрелками после перехода к сцене клавишей Tab.
