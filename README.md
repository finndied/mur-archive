# Мур.архив

Мобильный фотоальбом Джузо и Моти на React, Vite и Three.js. В «Мур.почте» можно оформить открытку и скачать PNG 1080 × 1350.

## Запуск

```sh
yarn install
yarn dev
```

`yarn build` собирает сайт в папку `dist`.

## Вход и синхронизация на Vercel

1. Создайте или выберите проект Supabase. В его SQL Editor по очереди один раз выполните [миграцию аккаунтов](supabase/migrations/20261121000000_mur_accounts.sql) и [миграцию входа по логину](supabase/migrations/20261121000001_mur_usernames.sql). Если таблицы и хранилище уже созданы, примените только вторую миграцию.
2. Оставьте включённым провайдер **Email** в Supabase Auth. Сервер использует его для проверки пароля по внутреннему адресу аккаунта.
3. В проекте Vercel задайте `VITE_SUPABASE_URL` и `VITE_SUPABASE_PUBLISHABLE_KEY` для Production. Добавьте `SUPABASE_SECRET_KEY` как закрытую переменную для серверного обработчика `/api/accounts`, затем пересоберите сайт. Ключи берутся из **Project Settings → API Keys**. Переменная с серверным ключом должна оставаться без префикса `VITE_`.

Регистрация и вход на сайте используют логин и пароль. Фото, избранное и текущий черновик доступны с любого устройства после входа под тем же логином. Если у старого аккаунта ещё есть недавняя сессия, в профиле можно добавить логин и пароль и сохранить данные этого аккаунта.

Гостевые данные остаются в браузере. Кнопка «Перенести фото и избранное» копирует их в аккаунт, повторный перенос не создаёт дублей. Скачанные PNG сохраняются как файлы на устройстве.

В 3D-сцене можно потянуть фигурки мышью или пальцем. С клавиатуры ракурс меняется стрелками после перехода к сцене клавишей Tab.
