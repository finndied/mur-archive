# Мур.архив

Мобильный фотоальбом Джузо и Моти на React, Vite и Three.js. В «Мур.почте» можно оформить открытку и скачать PNG 1080 × 1350.

## Запуск

```sh
yarn install
yarn dev
```

`yarn build` собирает сайт в папку `dist`.

## Вход и синхронизация на Vercel

1. Создайте или выберите проект Supabase. В его SQL Editor один раз выполните [миграцию аккаунтов](supabase/migrations/20261121000000_mur_accounts.sql). Она создаёт закрытое хранилище фото и таблицы для личного избранного и черновика открытки.
2. В Supabase включите вход по email, оставьте шаблон письма со ссылкой и задайте адрес опубликованного сайта в **Authentication → URL Configuration → Site URL**. Добавьте точные разрешённые адреса возврата, включая `http://localhost:5173/` для локальной проверки. Для отправки писем адресатам за пределами команды Supabase нужен [свой SMTP-сервис](https://supabase.com/docs/guides/auth/auth-smtp).
3. В проекте Vercel задайте `VITE_SUPABASE_URL` и `VITE_SUPABASE_PUBLISHABLE_KEY` для Production и пересоберите сайт. Скопируйте URL и ключ **Publishable** со страницы подключения проекта Supabase. Для локального запуска можно записать их в `.env.local` по примеру `.env.example`. Используйте только публичный ключ для браузера.

При входе под одной почтой фото, избранное и текущий черновик появятся на любом устройстве. Гостевые данные остаются в браузере. После входа в меню аккаунта можно скопировать гостевые фото и избранное в аккаунт. Повторный перенос тех же снимков сохраняет их в тех же местах без дублей. Скачанные PNG сохраняются как файлы на устройстве.

В 3D-сцене можно потянуть фигурки мышью или пальцем. С клавиатуры ракурс меняется стрелками после перехода к сцене клавишей Tab.
