# Мур.архив

Мобильный фотоальбом на React, Vite и Three.js. В галерее шесть разных фотографий из восьми вложений. Избранное хранится в браузере.

## Запуск

```sh
yarn install
yarn dev
```

Для сборки выполните `yarn build`. Готовый сайт появится в папке `dist`.

В 3D-сцене можно потянуть фигурки мышью или пальцем. С клавиатуры ракурс меняется стрелками после перехода к сцене клавишей Tab.
